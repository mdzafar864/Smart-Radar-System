# Demo Video

A short demo of the Smart Radar System in action (servo sweep, live
Processing visualizer, and buzzer alerts).

🔗 **Watch here:** https://youtube.com/shorts/AxBbinlzzF8?si=7KXWETVOZmPvtYAb

## Recording Tips

- Show the physical build (Arduino + servo + HC-SR04 + buzzer) alongside the
  Processing visualizer window so viewers see input and output together.
- Move an object toward/away from the sensor to demonstrate the
  distance-based buzzer pitch changes (close / near / in-range).
- Keep it under 60–90 seconds for a repo demo.
